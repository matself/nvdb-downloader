about=Download NVDB road data (road network, speed limits, road classes, road numbers and more) from Trafikverket's open API for the current map extent, saved as GeoPackage in SWEREF 99 TM. The first tab fetches any single NVDB table. The second tab fetches ready-made presets; the main one builds one road network layer for cars, bikes and pedestrians by joining several NVDB tables, and styles it with a style derived from Lantmäteriet's open Topografi 10 style. Covers Sweden only. Requires a free API key from data.trafikverket.se, stored in the QGIS authentication database. No extra Python packages are needed. The user interface is in Swedish; the README contains an English guide to every control and message. The plugin is independent and not developed by Trafikverket or Lantmäteriet.
